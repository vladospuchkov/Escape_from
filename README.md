# Escape From

**Escape From** — учебный хоррор-проект на Unity от первого лица. Игрок должен выбраться из охраняемого комплекса, пройти несколько этажей, найти ключ-карту, патроны, батарейки, джетпак и улететь к финальной платформе.

## Основные возможности

- игра от первого лица;
- фонарик с зарядом батареи;
- оружие и патроны;
- роботы-наблюдатели с ИИ;
- двери и интерактивные комнаты;
- предметы для подбора: ключ-карта, патроны, батарейки, секретные документы, джетпак;
- фоновая музыка и звук выстрела;
- экран проигрыша и победы;
- меню паузы с настройками громкости, чувствительности мыши и качества графики;
- автоматический запуск игровой сцены без стартового меню.

## Требования проекта

### 1. Меню с настройками

В проекте есть меню паузы с настройками:

- громкость;
- чувствительность мыши;
- качество графики.

Игра запускается сразу в игровую сцену, чтобы не мешать тестированию.

### 2. Аудио-контент

В проект добавлены аудиофайлы:

- `Assets/Audio/shot.wav` — звук выстрела;
- `Assets/Audio/background.wav` — фоновая музыка.

Также используются процедурные звуки для некоторых игровых событий.

### 3. 3D-модель из Blender

В проекте присутствует 3D-модель робота:

- `Assets/Models/BlenderRobotGuard.obj`

Исходные материалы Blender находятся в папке:

- `BlenderSource`

### 4. Искусственный интеллект

ИИ наблюдателей реализован в скрипте:

- `Assets/Scripts/GuardAI.cs`

Используются:

- патрулирование по ключевым точкам;
- обнаружение игрока по расстоянию и углу обзора;
- преследование игрока;
- поиск последней позиции игрока;
- временное отключение робота после выстрела;
- конечный автомат состояний.

Состояния ИИ:

- `Patrol` — патрулирование;
- `Chase` — погоня;
- `Search` — поиск;
- `Disabled` — отключение после попадания.

Это закрывает требование по использованию алгоритма перемещения по ключевым точкам и простой системы ИИ.

### 5. Оптимизация

В проекте используется паттерн **Object Pool**:

- `Assets/Scripts/ObjectPool.cs`
- `Assets/Scripts/PooledAlarmEffect.cs`

Object Pool позволяет не создавать и не удалять объекты каждый раз, а переиспользовать уже созданные экземпляры. Это снижает нагрузку на память и уменьшает риск просадок FPS.

Также в проекте используются:

- переиспользуемые материалы;
- простая и легкая логика ИИ без тяжелых вычислений;
- процедурная сборка сцены через редакторский скрипт;
- ограничение количества активных игровых систем.

## Запуск проекта

1. Открыть проект в Unity.
2. Открыть сцену:

   `Assets/Scenes/EscapeFromGuard_Horror.unity`

3. Нажать `Play`.

Если сцену нужно пересоздать:

`Tools > Escape From Guard > 0. CREATE FULL PROJECT: MENU + GAME`

После пересоздания стартовой сценой остается игровая сцена.

## Структура проекта

```text
Assets/
  Audio/        звуки и фоновая музыка
  Editor/       генератор сцены
  Materials/    материалы
  Models/       3D-модель робота
  Scenes/       игровые сцены
  Scripts/      игровые скрипты
BlenderSource/  исходники Blender
Packages/       зависимости Unity
ProjectSettings/ настройки проекта
```

## Версия Unity

Проект создавался под Unity `2022.3.20f1`.

При открытии в более новой версии Unity возможны предупреждения, но проект можно адаптировать под новую версию.
